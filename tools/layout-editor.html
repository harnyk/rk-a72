rk-a72 TUI layout editor

Internal tool for authoring the A72's on-screen key geometry (used by rk-a72-tui to render the keyboard). Grid unit = 1/4 of a standard key (a normal letter key is 4×4 units) — fine enough to place row stagger and the Alice split's offsets accurately. Drag a key from the tray onto the grid. Click a placed key to select it, then use arrow keys to move it (1 unit/press) or Shift+arrow keys to resize it (Right/Left = width, Down/Up = height). Delete/Backspace unplaces the selected key. Progress autosaves to this browser's local storage, so you can leave and come back across sessions on this machine. When done, click "Copy Rust code" and paste the result into rk-a72-tui's geometry table.

Faint gridlines = 1 unit (1/4 key). Bold gridlines = 4 units (1 standard key).
